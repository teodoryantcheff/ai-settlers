# Design the interface for economic analysis

The presentation direction was revised on 2026-10-15 by [ADR-0004](0004-full-map-and-game-windows.md). Precise economic information remains required; the earlier analytical presentation is historical context.

The interface serves professionals who understand the settlement premise and are chiefly interested in its economic simulation. Use an elegant, precise, informative presentation across all screens, prioritizing large desktop displays and allowing substantial information and workflow reorganization while preserving the existing game rules. Smaller-screen and mobile adaptation has lower priority.

The initial decision favored a less game-like presentation. On 2026-10-14, the user revised that visual direction: draw warmth and character from the painted settlement through earthy colors, resource illustrations, and restrained ornament, while preserving crisp numerical information, tables, and controls. The intended character is a carefully designed settlement atlas with quiet information surfaces; analytical clarity remains a requirement.
